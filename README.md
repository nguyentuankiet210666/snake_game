# 🐍 Snake Game

Một trò chơi **Snake (Rắn săn mồi)** đơn giản được xây dựng bằng **Python** và thư viện **Pygame**.

## 🎮 Chức năng

* 🐍 Điều khiển rắn di chuyển
* 🍎 Ăn thức ăn để tăng điểm
* 📈 Rắn dài ra sau mỗi lần ăn
* 💀 Game Over khi va vào tường hoặc thân
* 🔄 Chơi lại sau khi thua

## 🛠️ Công nghệ

* Python
* Pygame

## 📦 Cài đặt

Cài đặt Pygame:

```bash
pip install pygame
```

## ▶️ Chạy game

```bash
python main.py
```

## 🎯 Mục tiêu học tập

Project giúp luyện tập:

* Biến và kiểu dữ liệu
* `if / else`
* Vòng lặp
* Hàm
* List
* Xử lý sự kiện
* Game Loop
* Lập trình hướng đối tượng (OOP)
